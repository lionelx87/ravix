# Ravix

A spectacular, animated git TUI (binary `rx`). Rust + Ratatui. See `ROADMAP.md` for design pillars and phases.

## Finishing work

After every implementation or fix, run `/install-rx` (or `scripts/install.sh`) so the `rx` on this machine is the latest build.

## Agent skills

### Issue tracker

Issues and PRDs live in GitHub Issues at `lionelx87/ravix` (via the `gh` CLI); external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical five-label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), already created on the repo. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
